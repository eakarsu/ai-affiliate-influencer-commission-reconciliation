# Affiliate & Influencer Commission Reconciliation

Reconcile partner commissions to valid attributed orders, returns, tiers, bonuses, and fraud controls.

**Primary buyer:** Brands, networks, and ecommerce teams. **Evidence:** partner agreements, links, codes, clicks, orders, returns, attribution windows, commission tiers, bonuses, fraud signals, invoices, and payments.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Partner agreement library
- Tracking link code registry
- Click event ingestion
- Order attribution
- Attribution window control
- Coupon poaching detection
- Return cancellation reversal
- Commission tier calculation
- Performance bonus
- Self-referral detection
- Fraud traffic scoring
- Partner statement audit
- Dispute workflow
- Payment correction
- Partner campaign analytics
